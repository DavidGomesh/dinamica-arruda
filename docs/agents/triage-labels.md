# Triage labels

As skills usam cinco papéis canônicos de triagem. Esta tabela associa esses papéis aos valores empregados no issue tracker deste repositório.

| Rótulo em `mattpocock/skills` | Valor no tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Um mantenedor precisa avaliar a issue |
| `needs-info` | `needs-info` | Aguardando mais informações do autor |
| `ready-for-agent` | `ready-for-agent` | Totalmente especificada e pronta para um agente AFK |
| `ready-for-human` | `ready-for-human` | Exige implementação humana |
| `wontfix` | `wontfix` | Não será implementada |

Quando uma skill mencionar um papel de triagem, use o valor correspondente nesta tabela.

Caso o vocabulário do tracker seja alterado, atualize a segunda coluna para refletir os valores realmente usados.
